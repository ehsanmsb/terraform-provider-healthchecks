# healthchecks Provider

Terraform provider for Healthchecks.

Use this provider to manage Healthchecks projects, checks, integrations, and project members against either `healthchecks.io` or a self-hosted Healthchecks instance.
## Example Usage

```terraform
provider "healthchecks" {
  base_url = "https://healthchecks.example.com"
  username = var.healthchecks_username
  password = var.healthchecks_password
  timeout  = "30s"
}

variable "healthchecks_username" {
  type = string
}

variable "healthchecks_password" {
  type      = string
  sensitive = true
}
```

## Environment Variables

Because the provider example uses Terraform input variables, you can supply credentials and other settings with `TF_VAR_...` environment variables instead of hardcoding them in configuration files.

Example:

```bash
export TF_VAR_healthchecks_username="your-email@example.com"
export TF_VAR_healthchecks_password="your-password"
```

For optional provider settings, define matching Terraform variables in your configuration and pass them the same way, for example:

```bash
export TF_VAR_healthchecks_base_url="https://healthchecks.example.com"
export TF_VAR_healthchecks_timeout="30s"
```

## Schema

### Required

- `password` (String, Sensitive) Healthchecks account password for web-session login.
- `username` (String, Sensitive) Healthchecks account email/username for web-session login.

### Optional

- `base_url` (String) Base URL of the Healthchecks instance.
- `insecure_skip_verify` (Boolean) Skip TLS certificate verification for self-hosted instances.
- `timeout` (String) HTTP timeout, for example `30s`.



## Notes

- Authentication currently uses a username/password web session.
- Project, integration, and project member operations use authenticated web endpoints.
- Checks are managed through the Healthchecks Management API v3 with a project read-write API key.
